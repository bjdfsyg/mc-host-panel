🚀 Schnellstart – Windows PC

In 5 Minuten zum laufenden Minecraft-Server auf deinem Windows-PC.

Voraussetzungen

  • Windows 10 oder 11 (64-Bit)
  • Java 21+ – Adoptium Temurin 21 herunterladen
  • Mindestens 2 GB freien RAM

Installation

  1. Installer herunterladen "MC Host Panel Setup.exe" oben herunterladen und ausführen.
  2. App starten Desktop-Verknüpfung oder Start-Menü → "MC Host Panel".
  3. Lokal verbinden Im Verbindungsfenster unten links auf 🖥 Lokal klicken.
  4. Server-Verzeichnis wählen Im Tab "Einstellungen" ein Verzeichnis für den Server auswählen (z.B. C:\minecraft-server).
  5. Paper herunterladen Tab "Einstellungen" → "Paper herunterladen" → Minecraft-Version auswählen → Download starten.
  6. Server starten Grünen "Starten"-Button drücken. Die EULA wird automatisch akzeptiert.
💡 Der Server läuft auf Port 25565. Andere Geräte im selben Netzwerk können sich über deine lokale IP verbinden, die im Tab "Netzwerk" angezeigt wird.

Portfreigabe für Internet-Zugang

Damit Spieler von außerhalb deines Netzwerks verbinden können, muss Port 25565 (TCP) im Router weitergeleitet werden. Suche dazu in deiner Router-Oberfläche nach "Portweiterleitung" und trage deine lokale IP ein.

🐧 Server-Modus – Linux / VPS

MC Host Panel auf einem Linux-Server deployen — mit Passwort-Schutz und automatischem Start.

Voraussetzungen

  • Ubuntu 20.04+ / Debian 11+ (oder vergleichbar)
  • Node.js 18+ und npm
  • Java 21+ für den Minecraft-Server

Installation

# Node.js installieren
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Java 21 installieren
sudo apt install -y openjdk-21-jdk-headless

# Panel herunterladen und installieren
git clone https://github.com/dein-user/mc-host-panel.git
cd mc-host-panel
npm install --omit=dev

Konfiguration (.env)

cp .env.example .env
nano .env
# .env
PANEL_USERNAME=admin
PANEL_PASSWORD=dein-sicheres-passwort
PORT=3000

Als systemd-Service einrichten

sudo nano /etc/systemd/system/mc-host-panel.service
[Unit]
Description=MC Host Panel
After=network.target

[Service]
Type=simple
User=minecraft
WorkingDirectory=/opt/mc-host-panel
EnvironmentFile=/opt/mc-host-panel/.env
Environment=PANEL_MODE=server
ExecStart=/usr/bin/node server.js
Restart=always

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable mc-host-panel
sudo systemctl start mc-host-panel
⚠️ Setze immer ein starkes Passwort, wenn das Panel über das Internet erreichbar ist!

🐳 Docker

MC Host Panel mit Docker Compose in wenigen Minuten deployen.

docker-compose.yml

version: '3.8'
services:
  mc-panel:
    build: .
    ports:
      - "3000:3000"
      - "25565:25565"
    environment:
      - PANEL_MODE=server
      - PANEL_USERNAME=admin
      - PANEL_PASSWORD=dein-passwort
    volumes:
      - minecraft-data:/data/minecraft
      - panel-config:/root/.mc-host-panel
    restart: unless-stopped

volumes:
  minecraft-data:
  panel-config:

Starten

# Image bauen und starten
docker compose up -d

# Logs anzeigen
docker compose logs -f

# Stoppen
docker compose down
💡 Das Panel ist dann unter http://server-ip:3000 erreichbar. Port 25565 ist der Minecraft-Server-Port.

⚙️ Panel konfigurieren

Server-Einstellungen (Tab: Einstellungen)

  • Server-Verzeichnis – Ordner wo der Minecraft-Server liegt
  • JAR-Datei – Name der Server-JAR (standard: server.jar)
  • Java-Pfad – Pfad zu Java (standard: java aus PATH)
  • Min/Max RAM – z.B. 512M und 4G
  • Neustart bei Absturz – Automatisch neu starten wenn Server crasht

Server-Typen

  • Paper – Empfohlen für Plugins, direkt über das Panel herunterladbar
  • NeoForge – Für Minecraft-Mods, Installation über Tab "Einstellungen"
  • Fabric – Leichtgewichtige Mod-Plattform, ebenfalls automatisch installierbar
  • Spigot / Forge – JAR manuell ins Server-Verzeichnis legen

Konfigurationsdatei

Alle Panel-Einstellungen werden in ~/.mc-host-panel/config.json gespeichert.

🧩 Mods & Plugins

Mods suchen und installieren

  1. Tab "Mods & Plugins" öffnen
  2. Loader und MC-Version einstellen z.B. Fabric, 1.21.1
  3. Suchen Name eingeben, Plattform wählen (Modrinth / CurseForge / Beide)
  4. Installieren Klick auf "Installieren" – Datei wird automatisch heruntergeladen

CurseForge API-Schlüssel

Für CurseForge-Suche wird ein kostenloser API-Schlüssel benötigt:

  1. Auf console.curseforge.com registrieren
  2. API-Schlüssel generieren
  3. In Tab "Mods & Plugins" → Einstellungen eintragen
💡 Modrinth ist kostenlos ohne API-Schlüssel nutzbar und enthält die meisten modernen Mods.

💾 Backups

Manuelles Backup

Tab "Backup" → "Jetzt sichern". Das Panel sendet vor dem Backup automatisch save-all und save-off an den laufenden Server.

Automatische Backups

  • Backup-Verzeichnis – Wo Backups gespeichert werden (z.B. C:\minecraft-backups)
  • Intervall – Alle X Stunden automatisch sichern
  • Aufbewahrung – Maximale Anzahl Backups (ältere werden gelöscht)

Auto-Neustart

  • Intervall – Server alle X Stunden neu starten
  • Vorwarnung – Spieler werden Y Minuten vorher im Chat benachrichtigt
⚠️ Stelle sicher dass das Backup-Verzeichnis auf einem anderen Laufwerk als der Server liegt um Datenverlust zu vermeiden.

🔧 Umgebungsvariablen

Das Panel wird über folgende Umgebungsvariablen konfiguriert (in .env oder direkt gesetzt):

Variable Standard Beschreibung
PANEL_MODE local local | server | electron
PORT 3000 HTTP-Port des Panels
PANEL_USERNAME admin Benutzername (Server-Modus)
PANEL_PASSWORD leer Passwort (Server-Modus, leer = kein Schutz)

🌐 Ports & Firewall

Standard-Ports

  • Port 3000 – MC Host Panel Web-Interface (HTTP)
  • Port 25565 – Minecraft-Server (TCP, für Spieler)

Portweiterleitung (Router)

  1. Router-Oberfläche öffnen meist 192.168.1.1 oder 192.168.0.1
  2. Portweiterleitung finden unter "NAT", "Firewall" oder "Portfreigabe"
  3. Regel hinzufügen: Externer Port 25565 → Interne IP deines PCs → Interner Port 25565 (Protokoll: TCP)

Linux-Firewall (ufw)

# Panel und Minecraft-Server freigeben
sudo ufw allow 3000/tcp
sudo ufw allow 25565/tcp
sudo ufw reload
💡 Deine öffentliche IP wird im Tab "Netzwerk" automatisch angezeigt. Port 3000 muss nur freigegeben werden wenn das Panel von außen erreichbar sein soll.
❓ FAQ

Häufige Fragen.

Muss ich Node.js selbst installieren?

Nein. Die Windows-EXE (Installer und Portable) enthält alles Nötige. Node.js ist bereits eingebettet. Nur Java 21 muss separat installiert werden.

Welche Minecraft-Server-Versionen werden unterstützt?

Paper für alle aktuellen MC-Versionen, NeoForge 1.20.1+, Fabric, Spigot und Forge (JAR manuell platzieren). Das Panel startet jede beliebige JAR-Datei.

Kann ich das Panel remote steuern (auf einem anderen PC)?

Ja. Starte das Panel im Server-Modus (start-server.bat / start-server.sh), dann ist es über Browser auf allen Geräten im Netzwerk erreichbar.

Wie sicher ist der Server-Modus?

Session-basierte Auth mit sicherem Secret, httpOnly-Cookies, Passwort-Hash nicht gespeichert. Für Internet-Zugang empfehlen wir zusätzlich einen HTTPS-Reverse-Proxy (nginx).

Was passiert mit dem Minecraft-Server wenn das Panel geschlossen wird?

In der Electron-App: Panel minimiert sich in die Systemleiste, der Server läuft weiter. Beim echten Beenden wird der Server gestoppt. Im Server-Modus läuft alles unabhängig.

Wo werden Einstellungen gespeichert?

Alle Panel-Einstellungen werden in ~/.mc-host-panel/ gespeichert — unabhängig vom Installationsort und bleiben bei Updates erhalten.

Unterstützt das Panel mehrere Server gleichzeitig?

Aktuell verwaltet eine Panel-Instanz einen Server. Für mehrere Server mehrere Instanzen auf verschiedenen Ports starten.

Wie aktualisiere ich das Panel?

Einfach den neuen Installer herunterladen und ausführen — er überschreibt die alte Installation. Einstellungen in ~/.mc-host-panel/ bleiben erhalten.
